# 터치 DJ 스테이션

LG 스탠바이미 2 같은 가로형 터치 화면에서 브라우저로 돌아가는 2덱 DJ 컨트롤러예요. 설치 없이 `index.html` 하나로 동작해요.

## 기능

- 덱 A/B: LP 플래터(스크래치·템포 밀기), 톤암 진행 표시, 피치 ±12%, CUE, 계속 맞춰주는 비트싱크
- 패드 모드: 핫큐 A–H, 비트 점프(1·4·8·16박), 롤(1/16–8박)
- 박 단위 루프(1–32박)
- 퀀타이즈: 핫큐 점프, 재생 시작(반대 덱 박에 맞춤), 효과 패드가 박에 맞춰 실행. 박보다 조금 늦게 누르면 바로, 일찍 누르면 다음 박에
- 폰 헤드폰(v18): 설정 > 폰 헤드폰을 켜고 폰으로 QR을 찍으면, 같은 와이파이나 폰 핫스팟에서 폰이 TV 시계에 맞춰 직접 재생해요. 스피커는 스테레오 그대로, 폰에서 덱별 CUE·믹스·볼륨·싱크 맞춤
- 렉박 플레이리스트를 빠짐없이 가져와요(v17에서 큰 플레이리스트 일부가 빠지던 문제 수정)
- 스킨 두 가지: 컨트롤러(금속 조그 링, LED 진행 링, 조그 가운데 화면, 고무 패드)와 기본(LP 레코드와 톤암). 설정에서 바꾸고, 성능은 같아요
- 모드 두 가지: 클래식(노브, 박 단위 루프)과 디지털(세로 EQ 슬라이더, 킬 버튼, 가로 필터, 루프 IN·OUT·EXIT/RELOOP, 길이 ÷2·×2, 루프 이동)
- 채널 페이더, 크로스페이더, FX 패드(환호·에어혼·라이저·다운리프터·에코), FX를 덱 A·B·둘 다 중 골라서 적용
- 파형: 3밴드 색상 파형, 4박마다 빨간 마디선, 위상 미터
- 렉박 USB 읽기: 플레이리스트, BPM, 핫큐(색상 포함), 메모리 큐, 비트그리드
- 곡 목록: 정렬, 어울리는 곡 추천(BPM ±6%, 키), 중복 숨기기, 틀었던 곡 표시
- 렉박 정보가 없는 음악 파일은 BPM과 비트그리드를 자동으로 계산
- 설정: 가벼운 모드(TV용), 블루투스 화면 지연 보정

## 렉박 USB 불러오기

**PC·노트북 크롬**: `USB 불러오기` → USB 맨 위 폴더(PIONEER와 Contents가 있는 곳)를 고르면 돼요.

**스탠바이미**: TV 브라우저는 폴더를 고를 수 없고, 대부분의 USB(FAT32)는 4GB가 넘는 파일을 담을 수 없어서 USB를 묶음 파일로 만들어 써요. Mac에 자동 업데이트를 한 번만 설치하면, 그다음부터는 렉박에서 USB로 내보내기만 하면 돼요.

**더블클릭으로 하기**: `tools/mac`의 `.command` 파일 3개와 `tools`의 파이썬·설치 파일을 USB 맨 위(`.command`)와 `.touchdj` 폴더에 넣어 두면, Mac에서 USB를 열고 더블클릭만 하면 돼요.

- `터치DJ 업데이트.command`: 지금 바로 이 USB 묶음을 업데이트
- `터치DJ 자동 업데이트 켜기.command`: 한 번 켜 두면 렉박에서 내보낼 때마다 알아서 업데이트
- `터치DJ 자동 업데이트 끄기.command`: 자동 업데이트 끄기

터미널로 하려면 Mac 터미널에 한 번 붙여 넣기:

```
curl -fsSL https://raw.githubusercontent.com/y2kjang-sudo/Touch-DJ/main/tools/install-mac.sh | zsh
```

- 렉박에서 내보내기가 끝나고 1분쯤 지나면 묶음을 알아서 업데이트하고, 끝나면 "이제 USB를 빼도 돼요" 알림이 떠요.
- 새 곡만 덧붙이고(마지막 묶음이 작으면 거기에, 크면 다음 번호로), 플레이리스트·큐가 담긴 `dj1_rekordbox.tar`는 매번 새로 만들어요.
- 묶음은 임시 이름으로 다 쓴 뒤에 바꿔 넣어서, 중간에 USB를 빼도 기존 묶음은 멀쩡해요.
- 아직 묶음이 없는 새 USB는 설치 명령을 다시 붙여 넣으면 만들지 물어봐요.
- 지우기: 같은 명령 끝에 ` -s -- --remove`

스탠바이미에서는 `파일 고르기`로 USB 맨 위의 `dj`로 시작하는 파일을 모두 고르면 돼요.

직접 실행하려면 `python3 tools/make_bundles.py /Volumes/USB이름` (처음부터 다시: `--rebuild`).

묶음 파일은 압축이 아니라 파일을 이어 붙인 것이라, 앱이 필요한 곡만 바로 읽어요.

## 알려진 한계

- 웹페이지라 블루투스 스피커의 소리 지연(0.2초 안팎)은 줄일 수 없어요. 설정의 화면 지연 보정으로 화면을 소리에 맞출 수 있어요.
- 마스터와 큐를 다른 출력으로 나눠 들을 수 없어요.
- webOS TV 앱은 USB에 접근할 수 없어서(LG 정책), 네이티브 앱 대신 브라우저로 동작해요.
